# Kalam Design Studio

پنل داخلی تولید طرح‌های خبری کلام تازه. این پروژه رابط Mini App، قرارداد API طراحی، کتابخانه دارایی‌ها و اتصال آن به n8n را به‌صورت ماژولار نگه می‌دارد.

## دامنه نسخه اول

- دسترسی فقط برای ادمین‌های مجاز تلگرام
- طراحی خروجی‌های خبری از متن موجود، بدون بازنویسی متن
- قالب‌های استوری 1080×1920 و پست 1080×1350
- انتخاب رسانه: کلام تازه، گلبهار و چناران
- استفاده واقعی از همه تصاویر ادمین یا استفاده از آن‌ها به‌عنوان مرجع الهام
- تولید زمینه با GPT Image 2 و رندر قطعی فونت، لوگو و متن فارسی

جزئیات فنی در [architecture.md](docs/architecture.md) و قرارداد درخواست در [design-request.schema.json](contracts/design-request.schema.json) قرار دارد.
